Tentang Project ini: <br>
Nama Project: Praktikum-laravel-c050425035 <br>
Berisikan latihan dalam mempelajari laravel lebih mendalam serta menampilkan data-data yang berasal dari database <br>
Langkah menjalankan project:
1. install composer, php, dan laravel
2. mengatur .env agar sesuai dengan database yang dipakai
3. migrate migrate
4. php artisan serve untuk menjalankan web
<br>
Perintah artisan yang digunakan:
1. php artisan make:model
2. php artisan tinker
3. php artisan make:migration
4. php artisan migrate
5. php artisan make:seeder
